06 / Technický plán

  • Prototypy: React, TypeScript, Vite, hash smerovanie, responzívne CSS. V plnohodnotnej aplikácii doplniť Tailwind, Zustand a Three.js / React Three Fiber až po schválení.
  • Dátová vrstva produktov oddelená od komponentov. Cena a technické parametre môžu byť prázdne; chýbajúce údaje sa nikdy nedopočítavajú z generického odhadu.
  • Výpočtový modul mimo UI: geometria v mm, produktové pravidlá, nosníky, upevnenie, terče a optimalizácia rezov. Najskôr obdĺžnik a testy hraničných prípadov.
  • 2D a 3D používajú rovnaký Project. SVG v Etape 0 je dizajnová ukážka; nenahrádza budúci overený 3D model.
  • GitHub Actions nasadí frontend na GitHub Pages. Objednávky, platby, nahrávanie fotografií a administrácia potrebujú samostatný backend.
  • Budúca administrácia: produkty, varianty, ceny, dostupnosť, fotografie, realizácie, články, objednávky a dopyty; role, audit a verzovanie montážnych pravidiel.
  • Právne texty a spotrebiteľské informácie sa pripravia na odborné schválenie v obchodnej etape.

07 / Schvaľovanie

Teraz zostávame v Etape 0. Po zverejnení troch konceptov čakáme na výber A/B/C a pripomienky. Až po výslovnom povolení nasleduje Etapa 1. Potom opäť čakáme na druhé schválenie pred programovaním e-shopu.
