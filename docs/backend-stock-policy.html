server/stock-policy.mjs vynucuje kompletný schválený katalóg. Názvy, artikle, varianty, rozmery, predajné jednotky, rabatové skupiny, presné ceny s DPH, zdrojové stránky, označenia skladového programu a celý zdrojový odtlačok musia súhlasiť s manifestom. Zmena ceny, nový artikel, vynechaný produkt alebo odlišný zdroj sú odmietnuté pred zápisom.

Spustenie a administrácia

Prázdne šifrované úložisko dostane schválený katalóg. Ak existujúce úložisko obsahuje nepovolený alebo pozmenený sortiment, server sa nespustí. Pôvodné údaje sa automaticky nemažú ani neprepisujú. Kontrola platí aj pre čítanie a zápis produktov v autentifikovanom administračnom API a pred výpočtom objednávky.

Prevádzkové údaje o potvrdenej skladovej zásobe a povolené obrazové či technické podklady môžu byť doplnené; zdrojové obchodné údaje zostávajú uzamknuté. Nový cenník potrebuje kontrolu, schválenie a aktualizáciu kanonického manifestu.

Cena s DPH nie je potvrdená sadzba DPH

PDF uvádza ceny s DPH, ale neuvádza percentuálnu sadzbu. Katalóg preto správne prijíma overenú cenu s DPH a vatRate: null. Neodvodzuje cenu bez DPH ani nevymýšľa daňovú sadzbu. Označenie „Skladový program“ alebo „Skladom do vypredania zásob“ nie je potvrdenou aktuálnou dostupnosťou.

Výpočet reálnej objednávky vyžaduje overenú daňovú sadzbu aj aktuálnu zásobu. Predvolená skladová politika navyše blokuje reálne objednávky aj pri nastavení oboch príznakov commerceApproved a commerceLive. Aktivácia potrebuje samostatnú kontrolu daňových a skladových údajov, konfiguráciu backendu a výslovný súhlas vlastníka. Platby nie sú aktivované.

Izolované testovanie

Testovací katalóg je možné vložiť iba explicitnou konfiguráciou v kóde s testOnly: true a objektom vytvoreným funkciou createTestOnlyCatalogPolicy. Objekt má súkromnú značku Symbol; obyčajný JSON ju nenahradí. Produkčný vstup server/start.mjs túto možnosť neposkytuje a žiadna premenná prostredia neobchádza skladovú politiku.
