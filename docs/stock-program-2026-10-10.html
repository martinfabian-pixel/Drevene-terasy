Ceny a varianty

  • Cena v košíku je presná primárna cenníková cena za ks alebo balenie. Nepoužívajú sa rabaty, prirážky ani individuálne zľavy.
  • Zaokrúhlená informačná cena za bm je samostatný údaj z PDF. Cena za kus sa z nej neprepočítava.
  • Rôzne dĺžky a rozmery rovnakého názvu sú varianty jedného detailu. Každý variant zachováva vlastný artikel a cenu. Rovnaký názov uvedený vo viacerých sekciách zachováva kategóriu PDF pri každom variante.
  • Údaj „Skladový program“ ani „Skladom do vypredania zásob“ nie je potvrdením aktuálnej zásoby.
  • PDF neuvádza sadzbu DPH; známe ceny obsahujú DPH, ale rozdelenie na základ a daň ostáva nepotvrdené. Obsah balenia a objem náteru sa nevymýšľajú.

Ďalší cenník bez ručného prepisovania

  1. Vložte nový PDF súbor do pracovného projektu. Overte jeho pôvod a dátum.
  2. Spustite pripravený extraktor. Číta tabuľkové bunky a grafické krúžky; pri neznámom formáte, chýbajúcom riadku, jednotke, krúžku alebo duplicitnom artikli import zastaví.
  3. Výsledný JSON manifest nahrajte v lokálnej administrácii v sekcii importu manifestu. Zobrazí sa prehľad cenových zmien a nový zdroj. Verejné ceny sa v tomto náhľade nemenia.
  4. Porovnajte manifest a prehľad zmien s novým PDF. Nové, odstránené alebo zmenené artikle vyžadujú samostatné výslovné schválenie sortimentu; cenový import ich nepustí.
  5. Po schválení sa aktualizuje aktívny dátový súbor a nezávislý kontrolný záznam, spustia testy a commit nasadí GitHub Actions. Ručné prepisovanie jednotlivých cien nie je potrebné. Produkčný administračný upload vyžaduje pripojený autentifikovaný backend.
python -m pip install -r scripts/requirements-stock.txt
python scripts/import-stock-pricelist.py novy-cennik.pdf \

Nástroj vytvorí JSON, úplný článkový CSV a strojový prehľad zmien. Rozsah strán je nastaviteľný cez --first-page a --last-page. Neznáme nové rozloženie vyžaduje úpravu extraktora a nový audit, nie odhad údajov.

Pri importovaní nového manifestu sa metadáta nového PDF zobrazia ako čakajúci zdroj (pendingSource) a uložia sa aj do exportu lokálneho návrhu JSON. Pôvodný schválený zdroj pri produktových záznamoch zostáva zachovaný do schváleného nasadenia. Import ani obnovenie lokálneho JSON nedokážu publikovať cenu, dostupnosť, fotografiu alebo montážne pravidlá.

Ochrana verejného sortimentu

Verejný katalóg je nemenný schválený zdroj. Administračné CSV/JSON importy sú oddelené lokálne návrhy, ktoré sa nepremietnu do vyhľadávania, odporúčaní ani plánovača. Ručné vytváranie nového artikla alebo variantu je vypnuté. Odstránené demo položky sa vyradia aj z uložených košíkov a projektov.
