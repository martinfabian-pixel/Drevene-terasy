Drevené terasy
Funkčná predajná platforma — náhľad

Existujúci repozitár, dizajnový smer 2027. Archív dizajnov zostáva zachovaný. Toto nasadenie neaktivuje platby ani reálne objednávky.

Funkčné časti

  • Katalóg všetkých desiatich kategórií, vyhľadávanie, filtre, porovnanie do troch materiálov.
  • Detail konkrétneho variantu: profil, dĺžka, množstvo, čistý plošný prepočet, prepojenie na plánovač.
  • Košík s validovaným lokálnym uložením, úpravou množstva a exportom. Množstvo dosiek/profilov je celočíselný počet fyzických kusov; predajná hodnota pri bm/m² sa prepočíta podľa variantu. Balenia sú celé jednotky, pri litroch je povolené zlomkové množstvo. DPH vychádza iba z výslovne zadanej sadzby; neznáma sadzba sa neodhaduje.
  • Pokladňa ako nezáväzný dopyt: fakturačné údaje, firma, dodanie alebo odber, rekapitulácia, lokálny export. Kontaktné údaje sa automaticky neukladajú do localStorage.
  • Realizácia na kľúč a kontaktný dopyt: fotografie JPG/PNG/WebP, spolu do 10 MB, pripojenie uloženého projektu alebo JSON súboru, lokálny export vrátane príloh. Kontakty sa neposielajú na server ani sa automaticky neukladajú do localStorage.
  • Galéria jasne označených AI vizualizácií; žiadne neoverené realizácie, recenzie ani počty klientov.
  • Deväť odborných článkov s primárnymi zdrojmi a jasným rozlíšením všeobecného odporúčania od pravidla konkrétneho profilu.
  • Lokálne administračné demo: produkty, varianty, ceny, dostupnosť, používateľom vložený obrázok s neutrálnym popisom pôvodu a náhľadom, CSV import/export, kompletný JSON export/záloha s fotografiami a montážnymi pravidlami, náhľad textového obsahu.

Výpočtový návrh a jeho hranice

Interaktívny plánovač používa samostatný TypeScript modul a jeden výsledok pre 2D aj Three.js. Podporovaný výpočet sa viaže na platný pôdorys, konkrétny rozmer/profil, úplné pravidlá a vhodný podklad. Prípady, pri ktorých nie je možné spoľahlivo určiť výrobu alebo podporu dosiek, majú upozornenie a zablokovaný kusovník. Demo hodnoty nie sú schváleným montážnym návrhom.

Projekt možno explicitne uložiť v prehliadači, exportovať do JSON a priložiť k dopytu. Príloha zachováva aj typ podkladu. Tlač do PDF využíva systémový dialóg prehliadača. Podrobnosti: dokumentácia algoritmov a podporovanej geometrie.

Údaje a import

JAF kategórie sa pri automatickom overení nepodarilo načítať: všetkých päť odkazov vrátilo HTTP 403. Preto katalóg obsahuje výhradne označené demo položky, nie vymyslené výrobky JAF. Ceny, výrobca, aktuálna dostupnosť a technický list sú nevyplnené. Rozmery a montážne pravidlá seedovaných demo produktov sú iba demonštračné.

CSV používa jeden variant na riadok a hlavičku dostupnú v administrácii. Validuje ID, kategórie, jednotky, kladné rozmery, cenu, výslovnú sadzbu DPH a HTTPS dokumenty. Import je atomicky odmietnutý pri chybe; údaje ostávajú demo do odbornej kontroly. Export chráni tabuľkové programy pred vzorcami začínajúcimi =, +, -, @.

Kompletné montážne pravidlá ManufacturingRules sa pripájajú samostatným JSON. Povinné sú všetky technické polia vrátane minimálnej šírky a dĺžky rezu, rozstupov, výšok, škár, reznej škáry, výrobných dĺžok a pravidla čelných spojov. Overený režim vyžaduje HTTPS zdroj a výslovné potvrdenie odbornej kontroly. Samotné importovanie súboru nie je potvrdenie technickej správnosti.

  • Lunawood: vlastnosti a aplikácie: rozlíšenie hrúbky, montážnych rozstupov a použitia.
  • Lunawood Profix 2: systémový montážny prvok a súvisiaca dokumentácia.
  • Lunawood: technické a údržbové návody.
  • UPM ProFi: rodina systémov: rozdiely medzi profilmi, obytným a komerčným použitím, produktovo špecifická údržba.

Pripravený oddelený backend

server/ používa Node.js builtins bez ďalších balíkov. Nie je nasadený ani spustený cez GitHub Pages. Pripravené API obsahuje prihlásenie správcu, chránené kolekcie produktov/článkov/realizácií/objednávok/dopytov, príjem dopytu a deaktivovaný objednávkový endpoint.

  • Vyžaduje vlastný ADMIN_USER a náhodne solený scrypt hash hesla. Heslo sa generátorom číta zo stdin, nie z argumentu príkazu.
  • Session je náhodný token s 30-minútovou platnosťou, HttpOnly, SameSite=Strict, v produkcii Secure. Autorizácia administrátora a CSRF token pre zmeny.
  • Origin allowlist, limit veľkosti/tokov požiadaviek, rate limit, validácia vstupov a príloh, izolované idempotentné kľúče podľa endpointu.
  • Údaje sú uložené v súbore šifrovanom AES-256-GCM vlastným 32-bajtovým kľúčom. Zápis je serializovaný, atomický a fsync pred premenovaním. Kľúč musí byť zálohovaný oddelene; jeden proces vlastní dátový súbor.
  • Objednávka prepočítava cenu zo serverového katalógu, klientské ceny ignoruje. Vyžaduje overený produkt, cenu, DPH a štruktúrovanú dostupnosť so zásobou. Zásoba sa rezervuje atomicky; stav je awaiting-confirmation, platba sa nezačína.
  • Real orders vyžadujú súčasne COMMERCE_OWNER_APPROVED=yes a COMMERCE_LIVE=yes. V tomto projekte tieto hodnoty nie sú nastavené. Platobná brána neexistuje a nie je simulovaná.
  • Príjem dopytov vyžaduje ACCEPT_INQUIRIES=yes. Frontend v tomto náhľade používa lokálny export a neodosiela údaje na server.

Produkčné prihlásenie a chránené administračné UI majú byť na rovnakom origin ako backend, za HTTPS. Verejné /admin na Pages je jasne označené lokálne demo; nedáva prístup k serverovým dátam. Pred prevádzkou treba nastaviť hosting, TLS, zálohy, prístupové role, monitoring, obnovu/zrušenie rezervácií, firemné údaje, právne texty a schválenie spracovania zákazníckych údajov. Nejde o pripojenú produkčnú správu objednávok.

Čo ešte vyžaduje prevádzkovú konfiguráciu

  • Produkčná administrácia: nasadené HTTPS API, vlastné prihlasovacie údaje, role a chránené používateľské rozhranie. Verejné lokálne demo nie je produkčným prihlasovaním.
  • Katalóg: platný dodávateľský export, technické listy, výrobcovia, ceny a DPH, struktúrované zásoby, kompatibilita a práva na fotografie.
  • Dopyty: určený prevádzkovateľ, schválené spracovanie údajov, retenčné/delečné pravidlá, notifikácie a bezpečné zálohy. API pripravené v kóde nie je pripojená služba.
  • Objednávky: potvrdená cena dopravy a spôsob úhrady, zrušenie/uvoľnenie rezervácií, fakturácia a obchodné podmienky. Online platobná brána zostáva nenasadená.
  • Obsah: firemné kontakty a skutočné realizácie od majiteľa; schválenie odborných a právnych textov pred komerčným spustením.

Konfigurácia servera

Povinné environment polia: DATA_ENCRYPTION_KEY (64 hex znakov), ADMIN_USER, ADMIN_PASSWORD_SCRYPT (salt:hash), ALLOWED_ORIGINS (presné HTTPS origin). Voliteľné: DATA_PATH, API_PORT, API_HOST (vývoj iba loopback), NODE_ENV=production. Žiadne tajomstvá nedávajte do VITE premenných ani repozitára.

Príkaz node server/start.mjs spustí iba backend s dodanou konfiguráciou. Bez potrebných kľúčov odmietne štart. Komerčné prepínače zostávajú vypnuté.

Moduly a príkazy

Frontend: src/PlatformPages.tsx, src/commerce/, src/Planner2027.tsx, src/PlannerScene2027.tsx, src/engine/. API: server/app.mjs, domain.mjs, store.mjs, start.mjs. Pripravený klient src/commerce/api.ts má vypnuté odosielanie a overuje serverové capabilities; samotné načítanie modulu nezačne sieťovú operáciu.

Node 24: npm install, npm run dev, npm run build. Kontroly: npm run test:engine, npm run test:commerce, npm run test:server, npm run test:homepage, npm run test:platform, npm run test:platform-extra. Browser kontroly používajú skutočný build React DOM v Chromium a mobilné kontroly aj v engine WebKit. Nejde o overenie na fyzickom iPhone. Nasadenie Pages sa vykoná až po úspešných kontrolách workflow.

Testovanie

npm run test:commerce overuje prepočty jednotiek, validovaný košík, DPH, blokovanie demo predaja, CSV import/export, neplatné ID/kategórie/ceny a nekompletné montážne pravidlá. npm run test:server používa vlastný lokálny testovací server: autentifikácia, CSRF, allowlist, disabled orders, validácia, idempotencia, šifrovanie a serverový cenový prepočet. Testové osobné údaje sú fiktívne, testové súbory sa odstránia. Žiadna produkčná obchodná operácia sa nevykonáva.
