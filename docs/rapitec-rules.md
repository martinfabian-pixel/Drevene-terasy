## Rozhodovanie a priorita

Predpis konkrétnej dosky/profilu ostáva rozhodujúci pre rozstupy, škáry, polohu spoja, hlavu a systémové kotvenie. Predpis konkrétneho vrutu určuje jeho materiál, priemer, predvŕtanie a prípustnú aplikáciu. Splnené musia byť oba; rozpor vyžaduje potvrdenie, nie výber pohodlnejšej hodnoty. Žiadne pravidlo HPM sa automaticky nepriraďuje skrutke JAF iba podľa A4 alebo rozmeru.
